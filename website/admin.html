RELEASE READINESS

Sebelum konsol diaktifkan

  • ○
    Role admin diverifikasi di server

    Jangan mengandalkan route tersembunyi atau role yang dikirim browser.

  • ○
    Audit log tidak dapat diubah pengguna biasa

    Catat actor, action, waktu, objek, dan hasil tanpa menyimpan rahasia.

  • ○
    Alur moderasi dan banding disetujui

    Keputusan berisiko memiliki alasan, bukti, serta pemulihan yang jelas.

  • ○
    Rahasia vendor disimpan server-side

    OAuth token dan API secret tidak boleh ditaruh di JavaScript publik.
