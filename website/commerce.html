ETSY CONNECT · CHECKLIST

Mengaktifkan koneksi Etsy dengan benar

Etsy bukan konektor yang bisa aktif hanya dengan tombol di halaman statis. Kita perlu mendaftarkan aplikasi NARATIVA di portal Etsy, mendapatkan persetujuan API, lalu membangun callback OAuth dan backend untuk token.

  1. Tentukan jenis aplikasi. Seller App untuk toko milik sendiri; Personal App untuk pengujian/use case terbatas; Commercial Access diperlukan jika aplikasi akan melayani banyak penjual setelah proses persetujuan.
  2. Daftarkan aplikasi dan API key. Simpan keystring dan shared secret di konfigurasi server, jangan di HTML atau JavaScript publik.
  3. Siapkan HTTPS callback. Implementasikan OAuth 2.0 Authorization Code + PKCE, validasi parameter state, dan minta scope minimum seperti baca toko/listing atau tulis listing sesuai kebutuhan.
  4. Bangun fungsi backend. Tukarkan authorization code, simpan access/refresh token dengan aman, perbarui token saat kedaluwarsa, dan catat status koneksi per akun.
  5. Uji bertahap. Mulai dari membaca toko/listing, lalu sinkronisasi draft. Aktifkan pembuatan listing hanya setelah izin tulis dan hak distribusi konten terverifikasi.

Catatan: GitHub Pages hanya menyajikan frontend statis. Ia tidak boleh menyimpan Etsy shared secret atau refresh token. Untuk koneksi multi-user, kita perlu endpoint server-side—misalnya Supabase Edge Function—beserta tabel koneksi ber-RLS, enkripsi token, callback URL yang terdaftar, dan audit log. API access serta persetujuan Etsy tetap wajib; tidak boleh diakali dengan scraping.
